# Xray Reality + Vision 一键管理脚本

一键部署和管理 **Xray + REALITY + Vision (xtls-rprx-vision)** 的 Bash 脚本。

支持两种安装模式：

- **域名模式**：配合 Caddy 自动申请证书 + 本地伪装站
- **IP 模式**：无需域名，直接使用公网 IP + 真实网站伪装

---

## 功能特性

| 功能     | 说明                                   |
| -------- | -------------------------------------- |
| 安装服务 | 域名模式 / IP 模式一键部署             |
| 卸载服务 | 停止并清理全部组件                     |
| 查看状态 | 服务运行状态、端口监听、版本信息       |
| 查看参数 | 输出客户端 VLESS 分享链接与详细配置    |
| 管理用户 | 添加 / 删除 / 查看用户（实时重建配置） |
| 诊断自检 | 连不上时优先使用，只读检查，不修改配置 |

### 域名模式亮点

- 支持 **HTTP-01**（占用 80 端口）和 **DNS-01**（Cloudflare API，不占用 80）
- DNS-01 模式自动使用假邮箱，无需手动填写
- Caddy 本地伪装站，REALITY 流量最终落到真实 TLS 证书
- 自动处理常见 Web 服务（Nginx / Apache）端口冲突

### IP 模式亮点

- 无需域名、无需 Caddy
- 内置多个大型网站候选，并实测 TLS 1.3 握手
- 只展示握手成功的伪装目标，大幅降低「连上即断」概率

---

## 系统要求

- **操作系统**：Debian 11 / 12 / 13 或 Ubuntu 20.04 / 22.04 / 24.04
- **权限**：必须以 `root` 用户运行
- **网络**：服务器需能正常访问外网（证书申请与 REALITY 出网均依赖）

### 安装模式选择

#### 1. 域名模式（推荐有域名的用户）

1. 输入域名（例如 `example.com`）
2. 选择证书验证方式：
   - **HTTP 验证**：最简单，需放行 80 端口
   - **DNS 验证**：不占用 80，需 Cloudflare API Token
3. （HTTP 模式）输入 ACME 邮箱；（DNS 模式）自动使用假邮箱
4. 输入伪装站标题、监听端口（默认 443）
5. 脚本自动完成安装、证书申请与自检

#### 2. IP 模式（无域名场景）

1. 确认或输入公网 IP
2. 输入监听端口（默认 8443）
3. 脚本实测内置候选网站，选择一个握手成功的作为伪装目标
4. 完成安装并输出客户端参数

### 客户端配置要点

| 参数        | 域名模式           | IP 模式                       |
| ----------- | ------------------ | ----------------------------- |
| 地址        | 你的域名           | 服务器公网 IP                 |
| 端口        | 443（或自定义）    | 8443（或自定义）              |
| UUID        | 脚本生成           | 脚本生成                      |
| 流控        | `xtls-rprx-vision` | `xtls-rprx-vision`            |
| 传输        | tcp                | tcp                           |
| 安全        | reality            | reality                       |
| SNI         | 你的域名           | **伪装目标域名**（不能填 IP） |
| Fingerprint | chrome             | chrome                        |
| PublicKey   | 脚本生成           | 脚本生成                      |
| ShortId     | 脚本生成           | 脚本生成                      |

> **重要**：IP 模式下 SNI 必须填写伪装目标域名，不能填服务器 IP，否则客户端无法正常握手。

## 端口放行要求

| 模式               | 必须放行的端口                 |
| ------------------ | ------------------------------ |
| 域名模式 + HTTP-01 | TCP 80 + Xray 端口（默认 443） |
| 域名模式 + DNS-01  | 仅 Xray 端口（默认 443）       |
| IP 模式            | 仅 Xray 端口（默认 8443）      |

请同时检查：

1. 云厂商安全组 / 防火墙入站规则
2. 服务器本机防火墙（ufw / firewalld / iptables）

## 常见问题

### 1. 客户端「连上即断」

- **IP 模式**：伪装目标 TLS 1.3 握手失败。请重新安装并更换目标。
- **域名模式**：检查证书是否真正签发成功（尤其是 DNS-01）。

### 2. 客户端「连上但没网」

服务器出网受限。REALITY 认证通过后，流量需要服务器直连外网。检查机房线路、DNS 污染或限速。

### 3. DNS-01 证书申请失败

常见原因：

1. Cloudflare API Token 权限不足（需 `Zone.Zone:Read` + `Zone.DNS:Edit`）
2. Token 输错或已失效
3. 域名 NS 未托管在 Cloudflare
4. Token 作用域未包含目标域名

查看日志：

```bash
journalctl -u caddy-json -n 100 --no-pager
```

### 4. 连接异常优先做什么？

直接运行脚本的 **[6] 诊断自检**，它会检查：

- 服务状态
- 端口监听
- 出网连通性
- 伪装目标握手（IP 模式）
- 密钥配对
- 证书状态（DNS-01）
- 近期错误日志

## 注意事项

1. **必须 root 运行**，否则无法操作系统服务和防火墙。
2. DNS-01 模式会使用 `xcaddy` 编译带 Cloudflare 插件的 Caddy，首次可能需要 2–5 分钟。
3. 脚本会自动处理常见端口占用，但建议安装前确认 80/443（或自定义端口）空闲。
4. 卸载后请记得在云厂商安全组中删除对应放行规则。
5. 本脚本仅供学习与研究使用，请遵守当地法律法规。
